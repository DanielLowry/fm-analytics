# 03.6 — Visibility audit and release gate

## Goal

Review the complete path before external-player analytics begins.

## Audit surfaces

- memory-reader queries and raw wrappers;
- C# mapping, validation, errors, and logs;
- JSON schemas and golden responses;
- Python domain objects and exceptions;
- SQLite schema, migrations, and backups;
- notebooks, test reports, debug output, and exported recommendations;
- future model feature-generation interfaces.

## Gate questions

1. Can any consumer request underlying truth directly or indirectly?
2. Can a hidden value appear in an error, log, fixture, cache, or failed test?
3. Is extraction failure distinct from lack of manager knowledge?
4. Is stale knowledge distinguishable from a current observation?
5. Do derived scalar values record the uncertainty policy used?
6. Are unresolved semantics excluded by default?

## Exit criteria

- Findings are recorded and high-severity paths are closed.
- A regression checklist is attached to extraction-framework upgrades.
- Phases 04–06 have an approved set of permissible input fields.
