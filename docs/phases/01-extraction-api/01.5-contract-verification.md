# 01.5 — Contract verification

## Goal

Detect accidental incompatibility and information leakage before it reaches the
analytics application.

## Test layers

1. C# unit tests for mapping and validation
2. Endpoint tests against the fixture data source
3. Python decoding and domain-validation tests
4. Golden sanitized responses shared between producer and consumer tests
5. A Windows live smoke test kept small enough to run manually after framework
   or game-version changes

## Required cases

- known, ranged, and unknown observations;
- omitted optional fields and unknown enum members;
- stable ID serialization;
- no-source and incompatible-source errors;
- collections with zero, one, and many items;
- a response rejected because hidden data appears in an unknown observation.

## Exit criteria

- CI-capable tests require neither FM20 nor Windows.
- The live smoke procedure is documented and produces sanitized evidence.
- Contract changes fail at least one producer/consumer test until deliberately
  accepted.
