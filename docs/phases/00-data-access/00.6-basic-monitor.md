# 00.6 — Basic live monitor

## Goal

Provide an intentionally small local interface early, so extracted fields can
be inspected, refreshed, and downloaded without waiting for the eventual
polished dashboard.

## Current interface

Run:

```bash
python3 tools/fm20_monitor.py
```

Then open `http://127.0.0.1:8765`. The page shows source status, in-game date,
human manager, controlled club when resolved, process/version information, and
observation time. It refreshes every 30 seconds and offers the underlying JSON
at `/api/status` or as a download from `/api/status.json?download=1`.

The server binds to loopback by default and has no third-party dependencies.
It uses the Phase 00 Linux probe directly and is therefore development tooling,
not the eventual UI architecture.

The first live verification served HTTP successfully and rendered the expected
responsive page in a headless browser. The API exposed source status, process,
version, date, and the detected human-manager record; club correctly remained
`null` because it was not resolved by either current relationship path.
