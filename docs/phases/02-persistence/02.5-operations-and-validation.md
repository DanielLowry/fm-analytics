# 02.5 — Persistence operations and validation

## Goal

Keep local save-derived history trustworthy and recoverable.

## Work

1. Choose a configured data-directory convention outside source-controlled
   files.
2. Enable appropriate SQLite journal and durability settings.
3. Provide schema-version and integrity checks.
4. Document consistent backup and restore procedures.
5. Test interrupted import and migration recovery.
6. Add data-quality checks for duplicate identities, impossible ranges,
   inconsistent club references, and time moving backwards unexpectedly.
7. Define retention only after actual volume is measured.

## Exit criteria

- Backup and restore preserve counts, schema version, and sampled observations.
- Corruption/incompatible schema produces an explicit refusal to write.
- Operational commands do not silently delete or rewrite history.
- Database files and backups are excluded from version control.
